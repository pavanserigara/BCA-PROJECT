# Technology Stack

## Core Technologies
- **Backend**: PHP (v7+)
- **Database**: MySQL (using PDO for connection)
- **Frontend Logic**: JavaScript (Vanilla)
- **Styling**: Tailwind CSS (CDN-based v3)
- **Icons**: Font Awesome 6.5.0 (CDN)
- **Typography**: Google Fonts (Plus Jakarta Sans, Inter)

## Infrastructure
- **Server**: Likely Apache/Nginx (standard PHP hosting)
- **Development Environment**: Local environment (WAMP/XAMPP/Localhost)

## State Management
- **Server-side**: PHP Sessions
- **Client-side**: LocalStorage (used for theme persistence)

## Design System
- **Theme**: Light/Dark mode support via Tailwind class-based logic
- **Components**: Custom glassmorphism-inspired UI components
- **Transitions**: CSS transitions and Tailwind utility animations
